# Glossário
| Termo | Significado |
|---|---|
| Rotina | Lista ordenada de exercícios com séries/reps/descanso alvo (ex.: Treino A) |
| Sessão de treino | Um treino feito numa data; pode ter rotina ou ser "treino livre" |
| Série | Um registro de carga × repetições; tipos: aquecimento (A), normal, falha (F), drop (D) |
| Última vez | Séries do mesmo exercício na sessão finalizada mais recente |
| Volume | Soma de carga × reps das séries concluídas, sem aquecimento |
| 1RM estimado | Carga máxima estimada por Epley: carga × (1 + reps/30), só de 1 a 12 reps |
| Recorde pessoal | Série que supera a melhor carga ou o melhor 1RM anterior do exercício |
| Treino de hoje | Próxima rotina na sequência A → B → C → A desde a última sessão finalizada (L1) |
| Fila de sincronização | Registros gravados no aparelho aguardando envio ao servidor |
| Modo local | Sem servidor: dados só no aparelho |
| Dados de exemplo | Registros fictícios com `exemplo: true` e selo EXEMPLO |
